The live system · one process, five threads

One thread writes. Everything else reads.

The log

Stores the sequencer’s output: every order, numbered. Not the fills: replaying the log re-creates them, and they must match.

UI bridge

Turns the newest engine frame into JSON. It skips old frames, so a slow browser can never slow the engine.

Websocket

Out, 30×/s: price, book, trades, races, profits, CPU, rings. In: start, stop, rule, B, speed, load.

Walk it in the numbered order. The browser sends a command (start, change the rule, change B, speed, load) over the websocket; the web edge (axum on tokio) passes it to the engine thread through the control ring. Step 1: inside the engine thread, the sequencer collects the agents’ orders into blocks of B milliseconds and sorts each block by the ordering rule. In market mode the price feed and the agents run on this same thread, so a run is deterministic. In stress mode there is no sequencer: a producer thread floods orders through the input ring, first come first served. Step 2: the order book matches each message, one at a time. Step 3: every numbered record goes out on three rings, one per reader. The log writer must see every record, so if its ring is full the engine waits: the log is the source of truth. It stores the input, the numbered orders, not the fills; after a run it is read back from disk and replayed through a fresh engine, and the fills must hash the same. The standby is a second engine fed the same records: it times each message and checks its fills against the primary’s. The UI bridge only needs the latest picture, so it drops old frames and never makes the engine wait. Step 4: it turns the newest frame into a JSON snapshot about 30 times a second, plus a one-minute history twice a second, and the web edge pushes them to every browser over the websocket. Timing detail, if asked: in stress mode the record goes to the log ring before matching; in market mode right after, on the same thread, which is equivalent because the run can be rebuilt from the scenario, the seed and the logged controls.
