This is the slide that untangles the vocabulary. The sequencer only decides order; the engine decides what an order means. In an order book, order is everything: first in line wins. Purple means built: we built the order book and all three sequencer rules, one active at a time, switchable live, and ran every rule on the same seeds. The batch auction is explained, not built. Each rule runs somewhere today. Robinhood Chain is first come, first served; its docs say priority gas auctions do not exist there (CoinDesk reported in October, from one anonymous source, that it is considering PGA). Arbitrum replaced Timeboost with PGA in September 2026: a fee auction inside each 125 ms round, ties to whoever arrived first. Hyperliquid is the closest to cancel priority: cancels run before orders that can trade in each block, though post-only orders go even earlier and takers can pay fees for earlier processing, never ahead of cancels.
