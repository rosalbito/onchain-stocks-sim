Latency is a number on a virtual clock, not a real network, so every run is deterministic: same seed, same bytes. The sequencer collects orders into blocks and sorts them by the rule we’re testing. The engine is the only thing that touches the book. The ledger tracks regular traders, LPs, snipers, the protocol and the chain, and the books always balance.
