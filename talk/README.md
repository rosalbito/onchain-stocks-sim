# Talk deck

Source of the slides for "Stale Quotes" (Subvisual, 26 Nov 2026), copied from the live deck on 26 Nov 2026.

- `deck/deck.json`: slide order and sections.
- `deck/deck.css`: shared styles (rosalbito.dev identity).
- `deck/slides/*.html`: one file per slide; the `<aside>` in each is the speaker notes.

The slides are meant for the Slides viewer they were built in; opening a file directly in a browser shows the content without the deck's frame.
